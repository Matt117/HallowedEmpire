A realm without a ruler

While the Hallowed Crusade fights the dark force in the east, the Lord Regent rules in the Emperor's name. Kingdoms have seceded. Bandits hold the roads. Villagers go missing in the night, and robed men preach that only the dead can save the living.

Adding Custom Maps

From the Steam Workshop

  1. Open the Hallowed Empire Workshop page in Steam and press Subscribe on a map.
  2. Start the game. Steam downloads the map and the game installs it for you.
  3. Pick it from User Maps in the lobby's Map list.

Unsubscribe to remove it again. A Workshop map never replaces one of your own maps with the same name.

By hand

A map is two files: MapName.json (the level) and MapName_logo.png (its preview picture). Copy both into your Levels folder:

%USERPROFILE%\AppData\LocalLow\Iron Foundry\Hallowed Empire\Levels
  1. Press Win + R, paste the path above and press Enter.
  2. Drop the .json and _logo.png files in, keeping the same name.
  3. Restart the game. The map shows under User Maps.

Sharing your own map

Build a map in the Level Creator, then choose File › Publish to Steam Workshop…. It uploads the map with its preview and opens the item page. Publishing the same map again updates it. First-time authors need to accept the Steam Workshop agreement on that page before the map becomes visible.
